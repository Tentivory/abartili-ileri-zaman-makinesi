# Abartılı İleri Zaman Makinesi

## Dünyanın En Ciddi, En Bilimsel ve En İşe Yaramaz Zaman Yolculuğu Aracı

Bu proje, insanlığın en büyük hayalini gerçekleştirmek için tasarlanmıştır: **ileriye gitmek**. Geriye değil. Asla geriye değil.

### Özellikler

- **%100 Çalışır**: Gerçekten zamanı ileri sarar. Saniye saniye.
- **Resmi Onaylı**: Hiçbir resmi kurum tarafından onaylanmamıştır ama öyleymiş gibi davranır.
- **Bilimsel**: Time.sleep() fonksiyonu kullanır. Bu, fizikçilerin bile kıskanacağı bir teknolojidir.
- **Güvenli**: Geri dönüş yoktur, bu yüzden paradoks riski sıfırdır.
- **Eğitici**: Sabır öğretir. Karakter inşa eder. Hiçbir işe yaramaz ama ruhunuza iyi gelir.

### Nasıl Kullanılır?

```bash
python zaman_makinesi.py
```

Program sizden kaç saniye ileri gitmek istediğinizi sorar. Cevap verin. Bekleyin. Geleceğe ulaşın. Hayatınız değişmesin.

### Uyarılar

- Bu makine sadece ileri gider. Geçmişe gitmek için başka bir evrende yaşamanız gerekir.
- 60 saniyeden fazla önerilmez. Evren yorulabilir ve siz de.
- Geri dönüş garantisi yoktur. Çünkü yoktur.
- Bu yazılım hiçbir sorunu çözmez. Ama çözmüş gibi hissettirir.

### Teknik Detaylar

- Dil: Python 3
- Bağımlılık: time, random (standart kütüphane, lüks yok)
- Performans: O(n) zaman karmaşıklığı, n = beklediğiniz saniye sayısı
- Test edildi: Evet, çalışıyor. İnanmayın ama deneyin.
